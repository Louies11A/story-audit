## 一、系统全景定位与题材分类速查表

网络文学历经二十年演化，已分化出高度成熟且壁垒分明的题材体系。不同题材的读者对于**“核心爽点驱动力”**与**“毒点容忍下限”**存在本质差异：
- **玄幻仙侠读者**绝不能容忍战力阶梯无脑吃书与主角圣母窝囊；
- **追妻火葬场读者**绝不能容忍女主被践踏后轻易回头的“廉价原谅”；
- **年代文读者**绝不能容忍超前私有化经商被时代铁拳无视的虚假悬浮；
- **规则怪谈读者**绝不能容忍主角未卜先知、机械降神打破推理解谜美感。

本知识库将 42 个主流网文题材的**第一性原理追读期待**与**绝不可触碰的毒点红线**结构化固化，为底层确定性引擎与顶层 4 专家矩阵提供不可动摇的对抗式审判依据。

系统根据叙事法则与力量/权力结构，将 42 题材解构为六大类别矩阵：

1. **仙侠玄幻矩阵**（传统玄幻、东方仙侠、都市修真、玄幻脑洞、玄幻言情、西方奇幻）

   - **审查第一法则**：严守战力绝对阶梯，无外部神明/至宝自爆级代价严禁越级；资源消耗与出装必须双向记账。

   - **核心特征**：现代社会法律秩序、生活压力、人际评价与超凡异能/特殊金手指的强烈对冲；
   - **审查第一法则**：超凡能力必须产生切实改变主角与家人现实社会地位的可见后果；拒绝脱离现代社会常识的悬浮降智。

3. **女频情仇与宅斗古风矩阵**（宫斗宅斗、古风世情、古言脑洞、豪门总裁、民国言情、年代、女频悬疑、女频种田、青春甜宠、双男主；短篇：追妻火葬场、宅斗宫斗、总裁豪门等）

   - **审查第一法则**：心死绝不廉价回头，智斗讲究规矩借势借力；严防现代网络嘴替当众犯法破坏时代沉浸感。

4. **科幻末世与竞技无限矩阵**（科幻末世、游戏体育、快穿）  
   - **核心特征**：极端生存压迫、秩序重建、科技数据蓝图与职业竞技规则；

#### 1. 叙述腔调与人称视界
第一人称「我」（多为女主）主导，轻快、自嘲、口语。主引擎是**内心吐槽小剧场**：表面言行与心理活动的反差制造喜感，嘴上「关你什么事」，心里「这人今天是怎么了？吃错药了？」。允许沙雕自称（本小姐 / 本公主 / 本喵）。只有心动瞬间才切慢镜头，放大身体微反应。

先虐后甜 / 救赎支线的前段换压抑克制腔：留白、不解释（《贪心》「没有。」我，撒了谎。他，没有回头。）。糖是熬出来的奖赏，一进糖区就切回轻快。

男主台词少而金贵。冰块脸 / 毒舌 / 病弱伪装均可，但开口必须是撩点或反差点，不给他解释性长台词。

#### 2. 开篇范式与黄金前三段
黄金简介一次抛出「关系错位 + 一句杀伤力台词」，误会即高概念。简介可以剧透反差点（他有多宠 / 他其实是谁），不剧透两人怎么走到一起。

#### 3. 钩子母题与事件升级链
甜宠的钩不是背叛升级，是**悬着的糖**：让心动、试探、选择和关系后果持续前推；若连续多个叙事单元没有关系变化，再检查是否停滞，不为逐节达标硬塞糖点。章尾可留疑点、情感悬置，也可给局部确认。

- **马甲 / 身份错位**（头号母题）：双马甲互撩、隐藏大佬、认错人、网恋对象是身边人。错位每次被触碰都应改变判断、策略或关系；不要逐节重复“差点戳穿又滑走”。
- **例外感投喂**：冰块男主只对女主破例。热橙汁、剔好刺的鱼、一支簪子。物件越小，例外越大。
- **强制同框装置**：赐婚 / 联姻 / 提亲堵门 / 病房陪护 / 住进同屋，把两人锁死在一个空间里日常发酵。
- **吃醋触发器**：前任、旧情传闻、男模。甜宠里情敌是工具不是威胁，功能是逼出占有欲和委屈。
- **「他好像瞒着我什么」**：深夜电话、被删的朋友圈、叫他爸爸的孩子。虐钩，短用，真相必须洗白。
- **危机见真心**：挡箭、发烧、受伤。嘴硬由行动戳破。

#### 5. 短篇专员审查卡尺
* **Agent A (资产/伏笔)**：短篇伏笔必须在 3-8 章内迅速回收闭环；出装物证（如验孕单、录音笔、遗物、钥匙扣）必须严格追踪。
* **Agent B (因果时空)**：短篇情节极速推进，严查伤害与反转因果脱节，保证受害者从隐忍到反杀的心理临界点坚实。
* **Agent C (排版质检)**：短篇注重窒息感与情绪冲击，单段超短句交替，台词狠话独立成段，过滤一切 AI 连词。
* **Agent D (对抗审判)**：严查“廉价原谅”、“圣母回头”、“反转生硬无伏笔”等短篇致死级毒点。

- **题材类型**：短篇爆发题材 | **所属大类**：短篇爆发 | **主流平台**：番茄 / 知乎盐言 / 黑岩 / 七猫
- **一句话定位**：番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
- 🧭 **第一性原理追读驱动**：被至亲至爱为白月光牺牲后彻底心死决绝离场；男主悔不当初发疯寻找，女主绝不回头扬眉吐气。
- 🚨 **绝不可触碰的毒点红线**：女主被虐千百遍男主下跪三秒钟就轻易原谅破镜重圆、虐女篇幅失控演变成厌女虐杀。

#### 1. 叙述腔调与人称视界
第一人称「我」受害者全程主导，贴体感和心跳走，毫不克制：疼就说疼，心死就说心死。双轨：前半委屈宣泄、眼泪决堤；撞破真相后切成冷静、反讽、居高临下的审判腔。句子白、口语，大量直给的内心独白和反问。**允许并鼓励向前剧透「火葬场」结局来吊人。**

开口就是带占有关系的称呼：「我老公 / 我丈夫 / 我未婚夫」。

#### 3. 钩子母题与事件升级链
密度极高：简介可密集呈现背叛，正文让背叛、心死、行动和后果持续升级；若连续多个叙事单元没有状态变化，再检查是否停滞，不为逐节达标另造背叛或狠话。**阶梯式背叛：道德 → 经济 → 生命。**

- **白月光触发链**（核心母题，几乎每篇都有）：男人有个白月光 / 小青梅 / 前妻 / 义妹，关键时刻为她牺牲妻子。白月光多用「娇弱委屈」人设当软刀。
- **偷听 / 撞破真相一次性砸**：无意听见渣男和同伙 / 白月光的真心话，全盘真相一次性砸下，是「心死」的导火索。
- **灾难期求救反被辱**：火灾 / 地震 / 绑架 / 早产时向丈夫求救，换来冷漠或咒骂，一步坐实「他根本不爱你」。
- **朋友圈配文当刀**：渣男 / 白月光发的甜蜜配文被主角刷到，配文越深情，刀越钝越疼。
- **数字 / 年限承重再清零**：结婚七年、陪你十年、八年替身，堆出投入再被一句话清零。
- **火葬场前瞻预告**：简介结尾或男视角插一句向前剧透 payoff（「我还不知道，他正发疯似的在国内找我」）。

## 五、全题材专员审查协同基线与规则契约

### 5.1 题材自动探测与动态白名单机制
审查系统在执行审查时，首先调用 `scripts/genre_detector.py` 的 `detect_genre()` 引擎，分析目标章节（或全书前几章）的自然文本，得到 `GenreProfile`：
1. **动态白名单注入**：根据题材特征，向 `format_scanner.py` 动态挂载专属面板关键词（例如玄幻挂载灵根道韵、末世挂载重构点舰体、年代挂载工分粮票、怪谈挂载污染度规则）；
2. **动态资产分类增强**：向 `ledger_engine.py` 注入题材特异资产分类（地契房产、规则诡器、身份特权、版权股权等），确保资产抽取百分之百归位；
3. **动态对抗卡尺激活**：向 Agent D 传递该题材的【第一性原理追读卡尺】与【特异性毒点预警】，使老书虫锐评直击该题材创作者的核心痛点。

### 5.2 题材特异性退出码裁定准则
在判定严重度时，必须结合题材第一性原理：
- **P0 致命阻断**：在玄幻仙侠中表现为“战力体系崩坏、死人无伏笔复活”；在追妻火葬场中表现为“女主被男主害死亲人后三句话原谅复合”；在规则怪谈中表现为“公然破坏绝对规则却安然无恙且无道具代价”；在年代文中表现为“七零年主角公开成立私人跨国集团未受惩治”。
- **P1 严重警告**：核心资产凭空掉落未记账、反派脸谱化弱智骂街送人头、跨章危机开局断崖丢失、煽情自嗨导致主线停滞超两章。
- **P2 局部打磨**：移动端大黑段 (>=120字)、拖沓长难句、疑似未认领暗线伏笔。
- **P3 建议微调**：AI 翻译腔连词、台词后动作混排堆砌。
