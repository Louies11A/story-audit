> 规范版本：v1.0  
> 适用角色：主审查协调器（Review Coordinator）及全体专家 Agent  
> 落地路径：`reports/LATEST_REPORT.md` 及逐章归档路径

---

## 一、严重度等级全景定义 (Severity Tiers)

审查系统将所有发现的缺陷严格划分为四大层级，各层级在工作流与自动化管道中具有明确的阻断契约：

| 级别 | 中文定性 | 核心内涵 | 典型触发场景 | 处置要求 | CI/管线状态码 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **P0** | **致命断裂** | 主线骨架坍塌、底层世界观吃书、物理时空绝对矛盾 | 1. 彻底死透的角色无暗线公然复活<br>2. 练气期凡人无外力秒杀筑基真修<br>3. 禁魔绝灵之地无解释违规御剑施法 | **绝对阻断**。必须重写或回滚，禁止发布。 | **Exit Code 2** |
| **P1** | **严重失误** | 资源凭空出装、核心因果跳跃、时序悬空、驱动力熄火 | 1. 账本未收录核心法宝突然出战<br>2. 前章重伤未愈次章一跃而起<br>3. 跨章生死危机开局不顾且无转场<br>4. 严重按头吃毒、脸谱化低智降智 | **本轮必修**。必须采纳修复方案并合入正文。 | **Exit Code 1** (带 `--strict`)<br>普通模式输出警告 |
| **P2** | **局部瑕疵** | 排版大黑块、长句拖沓、轻微视序漂移、伏笔待认领 | 1. 单段连续汉字 >= 120 字<br>2. 单句逗号 >= 4 个或 >= 45 字无标点<br>3. 视点转场连续超 800 字与主线脱轨<br>4. 正文中发现疑似暗线伏笔道具 | **建议顺手打磨**。提供短句切分示范，不阻断流程。 | **Exit Code 0** |
| **P3** | **润色建议** | AI 翻译腔堆叠、台词后动作混排、标点微调 | 1. 密集出现“然而、不可否认的是”<br>2. 对话引号后紧塞 80 字环境描写<br>3. 连用三个叹号的情绪滥用 | **作者自主选择**。提供去 AI 化纯净表达建议。 | **Exit Code 0** |

## 三、双方案短句修复数据契约 (PatchSpec Schema)

当用户决定采纳方案 1 或方案 2 并使用 `--apply-fix 1` 时，底层安全回写器（`scripts/safe_writer.py`）严格遵循以下结构化数据进行三行锚点消歧与原子替换：

```json
{
  "target_line": 42,
  "context_before": "悬崖之上阴风呼啸。",
  "old_text": "顾渊眼见对方扑来，从怀中摸出了一张威力绝伦的四阶灭神符箓，心中冷笑连连。",
  "new_text": "顾渊没有掏符。\n他反手拔出腰间青钢剑。\n剑尖斜挑，狠狠擦过岩壁。\n火星迸溅。",
  "context_after": "妖兽发出震耳欲聋的尖啸。"
}
```

### 三行锚点安全消歧契约：
1. **全局检索**：在全文搜索 `context_before + old_text + context_after`；
2. **邻域消歧**：若全文匹配数 > 1（网文高频短动作常见重合），以 `target_line` 为中心在局部邻域 `[target_line - 30, target_line + 30]` 内消歧匹配；
3. **安全拦截**：若邻域内仍有多重匹配或完全无匹配，**立即拒绝回写**，抛出异常，杜绝污染作者稿件。

## 四、报告归档目录收口路径与命名规则

所有报告统一归档至小说项目根目录下的 `reports/` 文件夹：

```
小说根目录/
├── reports/
│   ├── LATEST_REPORT.md                 # ⚡ 最新单章报告（始终覆盖写入，供秒查）
│   ├── .bak/                            # 🛡️ 正文回写前原子备份（{原名}_{时间戳}.bak）
│   ├── .cache/                          # ⚙️ 预审中间件（pre_audit_bundle.json）
│   ├── 单章审查/                         # 逐章归档（按百章分卷分层）
│   │   ├── 001-100章/
│   │   │   ├── 第001章_审查报告.md
│   │   │   └── 第031章_审查报告.md
│   │   └── 101-200章/
│   ├── 批量审查/                         # 多章连审专项报告
│   │   └── 2026-09-04_批量审查_第031-035章.md
│   └── 阶段封账与里程碑/                  # 分卷结转全书复盘
│       ├── 初始建账盘点报告_第001-030章.md
│       └── 第一卷_期末结账与全卷连续性审计报告.md
```
