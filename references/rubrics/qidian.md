# 起点中文网追读比模型卡尺 (qidian.md)

> 平台定位：阅文集团 / 起点中文网付费订阅与书友圈追读体系  
> 核心驱动力：追读比（次日/首周追读）、核心设定纵深、人物逼格、实力阶梯与日更生态

---

## 一、起点追读比核心评估模型

起点中文网商业逻辑由编辑排期推荐（新书入库→新书推荐→分江→六频→三江→强推）与追读比绝对主导。读者更注重世界观自洽度、力量体系严密性与长线期待感。

| 审查维度 | PASS 绿灯标准 | FAIL 追读门禁 (拦截项) | 追读比机理与读者反馈 |
| :--- | :--- | :--- | :--- |
| **3000字爽点节点** | 每 3000 字区间内至少具备 1 处扎实的情绪节点（实力破境、获宝解密、装逼打脸、破局智斗） | 连续 5000 字无有效情绪节点，全篇水字数或纯日常碎碎念 | 追读率呈断崖式下跌，新书期被编辑淘汰 |
| **50章实力晋阶** | 力量体系阶梯分明，每 50 章主角必须有实质性的阶层跨越（境界提升、职级跃迁或势力扩张） | 100 章主角实力原地踏步，战力通胀或反复在新手村兜圈子 | 读者产生“剧情停滞感”与“水分过大”差评 |
| **金手指在场率** | 核心金手指（功法、外挂、面板、穿越金手指）每章有交代、运用或推演深度 | 连续 5 章完全未提及核心金手指，遗忘主角立身之本 | 核心卖点脱节，读者失去代入感与确定预期 |
| **追读比门禁** | 章尾悬念 + 情绪连续性 + 次章期待感 → 预估次日追读比 > 30% | 连续 3 章无章尾钩子或情节断裂 → 预估次日追读比 < 15% | 触发推荐晋级淘汰线，无法登上首页强推与三江 |
| **日更节拍支持** | 大纲与单章容量充分支撑 4000-8000 字/天的连载节奏（每章 2000-3000 字） | 章节长度极不稳定（忽多忽少），单章情节无法形成独立节拍 | 书友圈催更疲软，连载黏性崩塌 |
| **角色立体度与智商** | 反派智商在线，配角立场鲜明，主角行事有城府与动机底线 | 出现脸谱化无脑送人头反派，配角成为纯NPC肉喇叭 | 引发高V书友本章说集体吐槽“降智毒草” |

## 二、起点专属四大审查卡尺

### 1. 3000字情绪节点严密性
* **节奏要求**：单章标准篇幅 2500-3500 字，每章必须承载至少一个微型闭环或阶梯推进。
* **情绪节点要素**：
  - 设定推演（展示金手指的深层机制）；
  - 社交反馈（同门、敌人、长辈或观众的震惊、敬畏与评判）；
  - 收益入账（灵石、功法、地位、地盘等具象资产落地）。

### 2. 力量体系与地图层级（50章晋阶律）
* **大境界节奏**：
  - 1-10章：新手村立足，金手指初显威；
  - 10-30章：首个小境界巅峰，打通区域资源；
  - 30-50章：突破大境界，引爆全宗门/全城关注；
  - 50章后：开启全新地图或更高维度冲突。
* **严禁**：同一种反派换皮反复送经验，境界升级只有数字变化没有战斗表现与社会地位改变。

### 3. 金手指深度推演
* 起点读者最厌恶“机械系统发奖励直接拉满”。
* **要求**：主角必须对金手指有探索、改造、利用漏洞或深度结合自身智谋的过程，体现“人役物而非物役人”。

### 4. 追读门禁红线
* 每章结尾必须保留“次日揭晓”的核心悬念，严禁全篇平缓收尾。
